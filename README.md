# DentalCare App 🦷

Aplicación web para la gestión de pacientes de una clínica dental.

La plataforma permite que los dentistas administren pacientes, registren visitas, suban imágenes de estudios (placas, radiografías, fotos clínicas) y agreguen observaciones.  
Los pacientes, por su parte, pueden ingresar a su cuenta para visualizar su historial, imágenes y comentarios realizados por el profesional.

## 🎯 Objetivo

Crear una aplicación fullstack desde cero, con arquitectura clara, seguridad, documentación técnica y buenas prácticas de desarrollo.

## 👥 Tipos de usuarios

- **Administrador (Dentista)**
  - Crear, editar y eliminar pacientes
  - Registrar visitas
  - Subir imágenes
  - Agregar comentarios
  - Gestionar usuarios

- **Paciente**
  - Ver su perfil
  - Ver historial de visitas
  - Ver imágenes y comentarios
